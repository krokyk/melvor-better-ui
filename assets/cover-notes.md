# Better UI artwork

The listing cover uses the same navy background, gold ornamental frame, gold serif title and colorful game-item illustration as the other Kroky mod covers.
The configuration icon uses the navy and gold palette of the Bardic Troupe icon.
The runtime ZIP includes `icon.svg`; the listing cover stays outside it.

## Generation

Generated with the built-in Imagegen tool, using the existing Mapmaking, Workforce and Armed to the Seeds covers as visual references.
The final cover is `assets/cover.png`.

## Prompt

Use a 16:9 cover from the same collection as the reference covers: midnight navy textured background, thin metallic gold frame with scooped corners, gold diamonds and side rules, and large cream-to-gold serif title reading “Kroky’s” and “Better UI” on two lines.
Below the title, illustrate a slate game interface panel with three gold-edged tabs, blue and teal inventory tiles, a blue quantity pill, a polished gold settings cog, a gold pushpin and a cream/gold cursor selecting a tile.
Use simple chunky illustrated game-item shapes, soft gradients and restrained bevels; keep the frame and title readable, with no extra copy, watermark or fake interface text.
